# kodedit-worker

Pekerja GitHub Actions untuk KodEdit.

- `zipflat.yml` — clone repo public, flatten, pecah ZIP (N fail setiap satu), bungkus ke satu ZIP besar dan terbit sebagai Release.
- Dicetuskan dari KodEdit (panel ⬇ ZIP → ☁ Proses di GitHub).

Repo ini perlu **public** supaya Actions percuma dan pautan muat turun Release boleh dibuka terus dari phone.
